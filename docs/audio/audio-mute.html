GUIDE · Audio

Mute speaker output

Silence engine audio without stopping voices or changing the mix.

In the editor

Right-click the top toolbar’s Play button and toggle Audio Enabled. The checked row and speaker icon show the current state. A speaker with an X means muted. The menu is available in Edit, Play and Paused states; a left click enters play mode only from Edit.

Audio starts enabled on a fresh profile. The choice is saved as audio.enabled in the editor preferences and applied at startup. Entering or leaving play mode keeps it. The Play button’s tooltip reports a mute made through the menu.

A recording keeps its sound: the output capture tap receives the full mix before speaker mute is applied.

In C++

#include "Audio/AudioSystem.h"
#include "Core/Engine.h"

if (auto* audio = GameEngine::EngineCore::GetInstance().GetAudioSystem())
{
    audio->SetMasterMuted(true);
    const bool muted = audio->IsMasterMuted();
    audio->SetMasterMuted(false);
}

Call this API from the thread that owns the audio system. The engine API changes the live state; the editor menu also saves its choice to the editor preferences. There is no managed binding for master mute.

While mutedBehavior
VoicesKeep playing and advancing. Unmuting uses the current mix, without restarting sounds.
Mixer volumesStay unchanged. New bus volume settings still apply when unmuted.
Speakers and metersSpeaker samples and the Master meter are zero. Child bus meters keep their own levels.
Output captureThe capture tap receives the original mix.
InitializationA mute set before Initialize is applied to the backend. The choice survives Shutdown and a later Initialize.
