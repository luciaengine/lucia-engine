Shared text effects

Text shadows, glow and outlines decorate shaped glyphs in the shared UI renderer. They do not change text measurement, wrapping, selection or caret placement. Effects apply to labels and controls that emit text through GlyphRunEmitter, including localized text and fallback glyphs.

Authoring

.title {
    text-shadow: 2px 3px 1px #000000cc;
    text-outline: 1px #102030;
    text-glow: 2px #50bfff80;
}

Lengths use logical pixels and scale with the display scale. Shadow offsets may be negative. Shadow blur must be nonnegative; omitting it creates a sharp shadow. An explicit color is required for the shadow shorthand. One shadow is supported; inset and comma-separated shadow lists are not supported. These are engine style properties, not a claim of complete browser CSS compatibility.

Malformed shorthand values are ignored as a whole, preserving an earlier valid declaration. Colors must be valid named, hexadecimal, or supported RGB/HSL functional values; nonfinite channels and overflowing numeric colors are rejected.

Use none to clear a shorthand. Each longhand inherits through the element tree and supports initial, inherit and unset. Transparent colors disable the corresponding effect. CSS transitions can interpolate the individual lengths and colors.

Drawing and clipping

Effects draw behind the glyph fills, including across multiple lines emitted by one element. Color glyphs contribute their alpha mask rather than their colors to an effect. Text effects follow the element's clipping: visible overflow allows effects outside the text box, while hidden overflow contains them. The effects do not enlarge the layout box.

Radius and rendering cost

Shadow blur and glow radius specify Gaussian sigma, with visible support extending to three times that value. Outline width, shadow blur and glow radius clamp to 64 device pixels after display scaling. Each enabled effect emits an additional glyph pass. Filtering work grows with the radius and covered pixels, especially for bitmap glyphs; use small radii for ordinary interface text and measure larger decorative effects on the target hardware.

C++ emission

UI::TextEffects is carried in the resolved visual style and primitive emission context. Custom text controls should use MakeGlyphRunTarget and EmitGlyphRun so style scaling, colors and effect emission stay shared. Authored colors use ARGB; target values are converted to the renderer's packed colors and device pixels by ResolveTextEffects.
