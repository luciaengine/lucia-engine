## Method

- Lucia reference: commit `e18015eea`. Current reference: `main` at `c7bb7343d` (#174).
- A Lucia line counts only when 3 tests agree. `git blame` at `e18015eea` gives a Lucia author. No version of the same file in OpenEngine history up to `be9186a74` has the line. No file on `main` has the line.
- CSS was compared per rule (selector and declaration). A rule that any OpenEngine version of the file had is OpenEngine content, not Lucia content. Example: OpenEngine changed many headings from `font-weight: 600` to `500` in `a5911638b`. Lucia only kept the older value, so that is not a Lucia change.
- Settings defaults, label strings, UXML structure and icons were compared by name.
- Each row was checked by behavior, not by class name. A class that is absent on `main` is often a rename. For example, `.context-menu-shortcut` became `.dropdown-item-shortcut` with the same look.
- Tier: **verified** means both sides were read. **Inferred** means the look or effect was deduced from the code, and no editor was started.

## Not Lucia changes

- Heading weights 600 against 500 in the inspector, settings, graphs and notices: OpenEngine changed them in `a5911638b`.
- The Settings search bar at the bottom and the mark-up region member list: these were older OpenEngine forms that OpenEngine replaced.
- `SearchDialog.css`: an OpenEngine file that OpenEngine deleted in `be9186a74`.

## Not audited

Be careful: this list is not complete for interaction.

- Interaction behavior inside the large panel files was compared only by labels, defaults and style. These files are `HierarchyPanel.cpp`, `SceneViewPanel.cpp`, `InspectorPanel.cpp`, `AnimationWindowPanel.cpp` and `CurvesGraphView.cpp`. The Lucia-only lines that were read there are method extractions with no new behavior. Not every line was read.
- UI module changes in `UIManager_Update.cpp`, `UIManager_Layout.cpp` and `UIManager_PrimitiveGen.cpp` were sampled. They are a split into named steps and a parallel primitive drain, with no visible change.
- No editor was started. No row has a screenshot.
- The Player and the tile map editor were not audited.

The raw lists for this audit are in the shared session notes, folder `lucia-ux-audit`: `css-lost.txt`, `missing-strings.txt` and `lucia-only.json`.
