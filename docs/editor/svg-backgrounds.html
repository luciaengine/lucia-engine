GUIDE · Editor appearance

SVG backgrounds

Editor and game UI render SVG backgrounds as raster textures. Use SVG files with CSS background-image just like other image assets; sizing, tint, repetition, border slicing, and rounded clipping use the texture path.

Choose a raster size

Search Settings for UI SVG Raster Size to choose the default raster bounds for SVGs shipped with the editor. The image keeps its aspect ratio. Higher values preserve more detail when enlarging icons and use more texture memory.

Use SVGs as project textures

Import an SVG into the project to use it as an ordinary RGBA texture, including in material texture slots. Open Project Settings → Asset Import → SVG Texture Import and choose Default Raster Size for project SVGs without a per-asset size override. This setting is independent of the editor UI raster size. Aspect ratio is preserved.

Raster size determines the texture resolution at import. Choose it for the largest on-screen size the texture needs; enlarging the texture later does not add detail.
