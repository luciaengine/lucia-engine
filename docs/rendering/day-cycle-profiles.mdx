---
title: Day Cycle profiles
description: Author tracks keyed to the sun's elevation and preview the scene's time of day.
---

Open **Day Cycle** from the editor's panel menu. The window starts with the
Default profile and shows a different profile after you select it in the asset
browser. The profile's inspector and the window edit the same working copy.

Use **Presets** to copy the tracks from Default or Clear Day into the working
copy. In the elevation view you can add, move, or remove keys. Switch to the
time of day view to see where those keys fall on this scene's solar path.
**Separate dusk** gives the afternoon and evening their own curve.

Drag the playhead to preview the hour in the scene. A preview leaves the scene's
saved time in place. If **Animate Time of Day** is on, releasing the playhead
commits the hour as an undoable edit and lets the clock continue. The scrub is
available in edit mode when the Sky Environment uses its clock to place the sun.

Use **Save** to write a project profile. Use **Save a copy to the project** to
copy a shipped profile into the project's `DayCycles` folder. The profiles
store track values for authoring. The scrub previews the sky's time of day.
