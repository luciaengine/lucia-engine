Procedural mesh colliders

Supply immutable CPU triangle geometry to a static physics body without a renderer or GPU mesh.

Register geometry

PhysicsECS::MeshColliderData::Register takes a Physics::MeshShapeDef by value and returns a generational handle. It rejects fewer than three vertices, empty or incomplete index triples, out-of-range indices and non-finite vertex positions. Check the handle before attaching a collider.

Physics::MeshShapeDef triangles;
triangles.vertices = {{-1, 0, -1}, {1, 0, -1}, {0, 0, 1}};
triangles.indices = {0, 2, 1};
auto data = PhysicsECS::MeshColliderData::Register(std::move(triangles));
if (!data.IsValid())
    return;
Components::MeshColliderShape shape;
shape.DataIndex = data.Index();
shape.DataGeneration = data.Generation();

Attach and replace

Attach the shape to an entity with Transform, WorldTransform, PhysicsCollider and a static PhysicsBody. Physics initialization builds the backend shape through the normal body lifecycle. Replace DataIndex and DataGeneration with a newly registered immutable mesh to request a rebuild. The physics system owns BuiltDataIndex and BuiltDataGeneration.

Static, self-owned body. This component describes a static triangle mesh on its own body entity. It does not route through a separate PhysicsColliderOwner. Dynamic triangle meshes are rejected. Use the normal convex or primitive shapes for dynamic bodies.

Own the lifetime

Keep each data handle alive until every referencing collider has been removed or changed to replacement data. Then call MeshColliderData::Release(handle). Registration, reads and release are thread-safe; Read returns shared immutable data that survives release. A stale handle cannot resolve to replacement geometry.

Generated entities should carry RuntimeOnlyEntity. Recreate their data and colliders from the generator's authored settings after loading a scene. Runtime geometry handles are not serialized. Keeping CPU geometry registered also supports rebuilding after the physics world restarts.

Contact materials

A mesh collider uses the same PhysicsCollider material assignment as other collider shapes. See contact surfaces and physics materials for authored .physmat assets and combine rules.
